# 📷 截图识字

一个 Windows 桌面小工具：**按一下快捷键截图，自动识别图片/视频里的文字，并复制到剪贴板**。

再也不用对着链接、文字手动打字了。程序常驻系统托盘，随时可用。

---

## ✨ 功能

- 🎯 **全局快捷键截图**：默认 `Ctrl + Win + X`，可在界面里录制改成你想要的任意组合键
- 🔤 **系统内置 OCR**：使用 Windows 自带的识别引擎，中文、英文都能识别，**无需联网、无需额外下载模型**
- 📋 **自动复制**：识别结果直接进剪贴板，Ctrl+V 即可粘贴
- 🖱️ **框选 / 全屏**两种截图方式，框选时用鼠标拉个框就行
- 🗨️ **实时反馈**：右下角弹出提示，还能听到“滴”的一声
- 🖥️ **系统托盘**：关掉窗口会最小化到托盘，程序一直在后台等着快捷键

---

## 🚀 安装（只需一次，约 1-3 分钟）

> 前提：电脑已安装 **Python 3.9+**。若没有，请到 [python.org](https://www.python.org/downloads/windows/) 下载安装，安装时**勾选 “Add python.exe to PATH”**。

1. 进入本项目文件夹 `截图识字`
2. **双击 `安装.bat`**，它会自动创建环境并安装依赖（需要联网，等待完成即可）

---

## ▶️ 使用

1. 双击 **`启动截图识字.bat`** 启动程序（会在后台运行，弹出设置窗口）
2. 关闭设置窗口会**最小化到系统托盘**，程序继续常驻
3. 随时按下 **`Ctrl + Win + X`**：
   - 如果是**框选模式**：屏幕上出现半透明选框 → 按住左键拉个框 → 松开
   - 识别到的文字自动复制到剪贴板，右下角弹出预览提示
4. 想改快捷键/截图方式/识别语言 → 点击托盘图标「显示主窗口」→ 设置 → **保存并应用**

## ⚙️ 常见问题

**Q：双击“启动截图识字.bat”点了没反应？**
- 先看黑色命令窗口有没有报错提示。新版的启动脚本会自动检查依赖并**显示具体错误**。
- 如果还是看不到原因，双击 **`调试启动.bat`** —— 它会以前台方式运行，任何报错都会直接显示在窗口里，把红色报错内容（或 `error.log` / `install.log`）发我即可。
- 常见原因：依赖没装完整 → 重新双击 `安装.bat`；或快捷键被别的软件占用。

**Q：按快捷键没反应？**
- 确认程序正在运行（看系统托盘里有没有蓝色小人头像）
- 确认快捷键没有被其他软件占用（例如某些录屏/截图工具）

**Q：提示“无法创建 OCR 引擎”？**
- 说明系统没装对应的识别语言。到 **设置 → 时间和语言 → 语言和区域** 添加中文/英文语言包即可（通常 Windows 已自带）。

**Q：识别不准？**
- 试试选“框选区域”模式，只框选目标文字，识别率更高。

**Q：想换 DeepSeek娘 的头像？**
- 程序左上角和系统托盘默认是内置手绘的 DeepSeek娘（大眼表情）。想换的话，把你自己喜欢的图命名为 **`mascot.png`** 放到 `截图识字` 文件夹里，重启程序即可自动使用。

**Q：想开机自动启动？**
- 按 `Win + R`，输入 `shell:startup` 回车，把 `启动截图识字.bat` 的**快捷方式**放进去即可。

## 🧩 技术说明

- 语言：Python + tkinter（界面）
- 截图：`mss`（多屏支持）
- 识别：`winocr`（纯 Python ctypes 调用 Windows.Media.Ocr 系统内置引擎），`winsdk` 作为 Python 3.12 及以下的兜底
- 全局快捷键：`keyboard`
- 剪贴板：`pyperclip`
- 托盘：`pystray`

依赖清单见 `requirements.txt`。

> **Python 版本**：本工具支持 Python 3.9 – 3.13。识别库采用纯 Python 的 `winocr`，
> 因此在 **3.13 上也能正常安装和运行**（`winsdk` 是编译扩展，仅 Python ≤3.12 才需要）。
